# OpenAI 2027 — Plan stratégique

Projet conceptuel indépendant proposant une refonte
des modèles, produits, infrastructures, finances et
services d'OpenAI pour 2027.

Ce dépôt n'est pas affilié à OpenAI.

## Organisation
- docs/ : chapitres du rapport
- idees/ : nouvelles propositions et décisions
- pandoc/ : configuration de publication
- assets/ : images et diagrammes
- build/ : documents générés

## Compilation
make pdf
make html
make clean

## Règles
Chaque proposition doit distinguer :
- Fait vérifié
- Proposition personnelle
- Hypothèse à valider
- Décision retenue
